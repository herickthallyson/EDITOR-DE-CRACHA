06 / Salvar edição

Este HTML abre com o projeto padrão já preenchido, incluindo a foto. Edite diretamente ou clique em Novo projeto para iniciar um crachá em branco. Para guardar alterações, use Salvar projeto editável (JSON). Restaurar projeto padrão recupera a versão embutida. Guarde o HTML e os projetos em local seguro; nenhum dado é enviado a servidores por este editor.
